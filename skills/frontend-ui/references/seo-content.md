# Search discoverability and content

- Decide which routes are public, indexable, and useful as search results. Put primary copy, meaningful headings, and navigable links in the rendered page. Give public routes distinct titles and descriptions.
- Coordinate canonical URLs, redirects, sitemap entries, and robots directives with the app's route policy. Return meaningful HTTP status codes for redirects and missing pages. Private content requires server authorization.
- Build share metadata from real page data. Add structured data only when it matches what the page visibly presents. Check metadata and canonical URLs on the actual response or the rendered output expected by the crawler.
- Check localized public routes consistently. Verify internal links, missing routes, redirects, and preview or staging indexing behavior after deployment.
